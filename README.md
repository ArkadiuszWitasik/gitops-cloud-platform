# GitOps Cloud Platform
Aim of this project is to learn creating Cloud infrastructure (AWS in this case) using tools such as Terraform. Then combine GitHub actions to push Docker image on every commit to ECR and deploy simple application and connect it with deployed database in secure environment.
## Functionality list
- AWS infrastructure to store and deploy app as Docker Image
- Secure AWS enviroment for web app and database
- New version of Docker image after commiting changes and deployment on cloud.
## Tech stack
App: FastAPI <br>
Database: PostgreSQL <br>
Cloud & Ops: AWS, Terraform, GitHub Actions, Docker <br>
